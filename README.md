# N2 — نیما در شهر نئون

بازی بیت‌م‌آپ موبایل با گرافیک نئونی و بامزه.

## ساخت فایل APK (بدون نصب هیچ برنامه‌ای)

1. در GitHub یک ریپازیتوری جدید بساز (مثلاً `n2-game`).
2. همه فایل‌ها و پوشه‌های این زیپ را آپلود کن (Add file ← Upload files و پوشه‌ها را بکش و رها کن).
   - اگر پوشه `.github` آپلود نشد: Add file ← Create new file، اسم فایل را `.github/workflows/build-apk.yml` بنویس و محتوای همان فایل را داخلش کپی کن.
3. به تب **Actions** برو. ساخت خودکار شروع می‌شود (حدود ۴ تا ۶ دقیقه). اگر شروع نشد، روی «Build N2 APK» و بعد **Run workflow** بزن.
4. وقتی تیک سبز شد، به بخش **Releases** ریپازیتوری برو و فایل `N2.apk` را روی گوشی دانلود و نصب کن.
   (اندروید یک بار اجازه «نصب از منابع ناشناس» را می‌خواهد.)

هر بار که فایلی را تغییر بدهی، APK جدید خودکار ساخته می‌شود و چون امضای برنامه ثابت است، روی نسخه قبلی نصب می‌شود.

## اجرای نسخه وب
همین ریپازیتوری را با GitHub Pages روشن کن؛ فایل `index.html` بازی است.

## ساختار
- `android/` پروژه اندروید (WebView تمام‌صفحه، افقی، لرزش، دکمه برگشت = مکث)
- `android/app/src/main/assets/index.html` خود بازی
- `src/` سورس جداشده بازی (کاراکترها، مراحل، منطق، منو)
- `build.sh` سورس‌ها را در `index.html` جمع می‌کند

کنترل با کیبورد (برای تست روی کامپیوتر): جهت‌ها یا WASD حرکت، J ضربه، K پرش، L ویژه، Esc مکث.
